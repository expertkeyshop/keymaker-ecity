### ZIP file structure

Upload the built website, not the source code and `node_modules`.

Your ZIP should contain the website files at its root:

```
ecitykeys-deploy.zip
├── index.html
├── assets/
│   ├── style.css
│   ├── script.js
│   └── images/
├── favicon.svg
├── robots.txt
└── sitemap.xml
```

That's an example structure; we'll preserve your existing file paths and build output.

### Deployment steps

1. Run your existing Node.js build script locally, if required.
2. Confirm the generated output contains `index.html` at its root.
3. ZIP the contents of that output folder.
4. Open [Cloudflare Dashboard](https://dash.cloudflare.com/?utm_source=chatgpt.com).
5. Go to Workers & Pages → Create application → Drag and drop your files.
6. Upload the ZIP and deploy.

Later, every new version can be uploaded through Create a new deployment.

Cloudflare's dashboard drag-and-drop method currently supports up to 1,000 files, with a maximum individual asset size of 25 MiB.&#x20;
